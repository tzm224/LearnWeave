# 教学与证据标准

## 逐页讲解应该增加什么

原页让读者看到材料；讲义让读者理解材料。不要仅把 bullet 翻译成中文或重复公式。对于实质页，至少解释一个原页容易省略的机制、推导步骤、变量含义、图示阅读顺序、代码运行行为或适用条件。无需给每页硬套相同长度。

整体总览用具体问题统领：本课试图解决什么，为什么前一种办法不足，接下来各章提供什么能力。章节主线必须从全篇读取得到，不能看目录就完成推断。

- **内容：** 先解释问题和直觉，再展开机制或形式化表达。图示指出节点、轴、箭头、阶段具体意味着什么；公式先说明表达的关系，再解释每个新符号；代码先说明目的，再解释关键状态变化和结果。
- **作用：** 定义、提出限制、建立工具、给出证据、应用、对比或总结。说明它在当前位置的贡献，避免“为后面打基础”这种任何页都适用的空话。
- **承接与引出：** 点出前页的具体结论或留下的问题，以及后页将如何处理。不要提前讲完尚未需要的内容。断开时写明是换章、补充或目前无法确认的联系。
- **保留的理解：** 用一句或少量几句压缩真正关键的能力或判断，不机械重述标题。

## 来源性质

| 标签 | 含义 | 例子 |
| --- | --- | --- |
| 课件内容 (`source`) | 原页或备注明确表达的事实、忠实解释 | 图中两条路径的梯度贡献要相加 |
| 补充解释 (`supplement`) | 为理解材料增加的背景、例子或展开推导 | 用标量链式法则展开被省略的一步 |
| 教学推断 (`inference`) | 从全篇重建的作用、联系或设计理由 | 此例将前页的规则落实到分支结构 |
| 待确认 (`uncertain`) | 具体、尚不能解决的来源歧义 | 第 12 页下标模糊，无法确认是 i 还是 j |

来源标签不表示“原材料一定正确”。发现可核实的错误时保留原页，准确说明哪里有问题及修正依据；不要静默改写原件。重要的课外 API 行为、时效事实或不确定专业事实，查官方文档或原始资料，在补充段落中附来源链接。离线阅读不应依赖打开这些链接才能理解正文。

## 公式、代码与渐进页

- 公式从图像核对，不能盲信 PDF 抽取符号。保持原符号体系，解释量的维度、对象和必要假设。区分局部导数、累积梯度、向量积等常见混淆。推导只展开帮助理解的步骤，不凭空增加未使用的公式。
- 使用常见 LaTeX 数学记法，避免自定义宏或外部扩展；KaTeX 报错必须处理。代码用 fenced code block，注释不要伪装成原代码。未经实际运行，不宣称验证过执行结果。
- 相邻页逐步补全同一图时，逐页说明新增节点、边或状态及其意义。只说“继续展示上一页”不合格；不能把最终页的内容声称为前页已经出现。
- 封面、版权、致谢和结束页保留定位，简短说明即可。原有练习保留题意和解释；不要无请求加入一套题库或考试系统。

## 知识图质量

概念是可复用的理解单元。例如“计算图”“链式法则”“梯度累积”通常比“第 8 页”“重要概念”“方法一”适合做节点。合并别名但保留区分所需条件。来源列表包含真正讲解或使用该概念的页，不把任意提到词语的页全部挂上。

边需要具体解释，例如“第 9 页的计算图把复合函数拆成局部运算，第 14 页在同一结构上反向组合局部导数”。“两者有关”“都属于本课”不能成为边的解释。相似性关系不写成因果；推导不写成时间顺序。证据不足时少连一条边比制造体系更有用。

## 人工/独立评审

抽查定义页、公式页、连续演示页、转章页以及至少一条跨章关系。评审者只拿技能、原始课件和产物，检查用户可观察的理解质量，不用测试断言去匹配固定措辞。优先修复错误公式、遗漏关键步骤、错配页码、无依据连线和不实作者意图；不要为统一文风无限润色。
